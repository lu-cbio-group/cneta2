# Contributing to CNETA

Thank you for considering a contribution. The contributing guide lives in
the documentation, so that there is one place to keep it up to date:

- Online: https://lu-cbio-group.github.io/cneta2/en/developer-guide/contributing.html
- Source: `docs/source/developer-guide/contributing.md`

It covers the workflow (branch from `main`, pull request, review, merge),
branch names, pull request titles and the git commands for each step. The
neighbouring pages of the developer guide cover building, testing and
working on the documentation.

If you use AI tools (GitHub Copilot, Claude Code, ChatGPT and the like),
please read the AI policy first:

- Online: https://lu-cbio-group.github.io/cneta2/en/developer-guide/ai-tools.html
- Source: `docs/source/developer-guide/ai-tools.md`

The instructions for the tools themselves are in `AGENTS.md`.

For a bug report, please open an issue with the CNETA version
(`cnetml --version`), the command line, and the error message or the
unexpected output.
