%   pdflatex -jobname=cneta-pipeline-dark \
%     "\def\PipelineScheme{dark}\input{cneta-pipeline}"
%
%   \PipelineScheme  light | dark   (default light): colours for a light or a
%                    dark background; the background itself stays transparent.
%
% Box colours follow the house convention of the report kit:
%   blue   a program step        grey    a file
%   green  a helper script       purple  an external tool
%   amber  settings to choose    red, dashed   in development
%
% Editing (details in README.md): each box is one \node line, its text in
% the braces, its centre at (x,y) in millimetres; arrows name the boxes.
